JSON içe aktarma biçimi

"GitHub'dan İçe Aktar" sekmesine, açık kaynak bir istasyon listesi barındıran raw.githubusercontent.com bağlantısını yapıştırman yeterli. Uygulama, aşağıdaki alan adlarından herhangi birini otomatik olarak tanır — böylece farklı projelerin JSON biçimleriyle de çalışır.

Beklenen JSON yapısı (esnek alan adları)

[
  {
    "name": "Radyo Eksen",              // veya "title" / "station_name"
    "url": "https://stream.example.com/live", // veya "url_resolved" / "stream_url"
    "genre": "Alternatif Rock",         // veya "tags"
    "country": "Türkiye",               // veya "country_name"
    "favicon": "https://example.com/logo.png"
  }
]
